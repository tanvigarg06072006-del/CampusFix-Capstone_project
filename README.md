# CampusFix

CampusFix is an intelligent campus issue reporting and resolution platform.

## Problem

Campus issues such as broken equipment, electrical problems, water leakage,
cleanliness issues and internet problems are often reported informally,
making them difficult to track and resolve.

## Solution

CampusFix provides a centralized platform where students can report campus
issues, track their status and receive updates.

## Planned Features

- Student registration and login
- Campus issue reporting
- Issue location and image upload
- Issue status tracking
- Admin dashboard
- Staff/department assignment
- Automated issue categorization
- Priority detection
- Duplicate issue detection
- Notifications
- Issue resolution history
